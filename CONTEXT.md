# Everforest Theme Distribution

This context describes the Everforest themes distributed to supported applications and how the project classifies them.

## Language

**Application Theme**:
The Everforest visual configuration provided for one target application.
_Avoid_: Integration, app module

**Home Manager Application Theme Catalog**:
The authoritative collection of Home Manager Application Themes and the platforms on which each theme is eligible.
_Avoid_: Application Theme Catalog, Platform Catalog, Integration Catalog
